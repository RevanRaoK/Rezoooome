- **Compact** (`rezoooo-wordmark-compact.svg`) for the sidebar header (next to a 28px icon) and the mobile top bar (alone). Minimum 16px tall.
- **Icon / favicon** (`rezoooo-icon.svg`, `rezoooo-favicon.svg`): the favicon file is tuned for 16–32px.
- Always use the SVG. Never retype the name as live text in a logo position.
- Consumer provides: the `<title>` in the format `Page name | rezoooo.me`, and alt text "rezoooo.me".
