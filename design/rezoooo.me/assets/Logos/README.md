# Logos

Single-ink rule: letters are `ink` (#1C1B19) and the 4th o is `orange-500` (#F26B1D). The full wordmark sets `.me` in `ink-muted` (#6B6964).

- `rezoooo-wordmark.svg`: full wordmark, minimum 24px tall.
- `rezoooo-wordmark-compact.svg`: sidebar and mobile header, minimum 16px tall.
- `rezoooo-icon.svg`: app icon (gauge o on an ink tile).
- `rezoooo-favicon.svg`: 16/32px tuned favicon.
- `rezoooo-wordmark-alt-gauge.svg`, `rezoooo-icon-alt-oo.svg`: alternates for comparison. Not for use unless chosen.
